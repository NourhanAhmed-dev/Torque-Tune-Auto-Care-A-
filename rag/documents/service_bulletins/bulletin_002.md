# Technical Service Bulletin TSB-2026-002 (Supersedes TSB-2025-001)

**Engine platform:** EcoBoost 2.3
**Category:** intake
**Effective date:** 2026-02-09

## Updated Guidance
This bulletin supersedes TSB-2025-001 (2025-10-18). Field data since the original bulletin shows the original inspection interval was too conservative; carbon buildup on intake valves (direct-injection engines) should now be checked at every service visit, not only when symptomatic.

## Recommended Action
Technicians must reference this bulletin, not TSB-2025-001, for current guidance on carbon buildup on intake valves (direct-injection engines). Any tuning log referencing the older interval should be flagged for review.
